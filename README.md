# The Rug Woke Up

A giant grizzly bear rises out of a bearskin rug in a wooden cabin — the rug is ALIVE.
Amber eyes lock onto the viewer, jaws open in a roar, fangs and tongue bared, one huge
clawed paw reaching straight out toward you.

Handwritten note pinned to the scene, in a child's hand:

> dear judge — grandpa said the rug was just a rug. grandpa was wrong. love, timmy (6) ♥

Why this one can move the top 1st: the current #1 (the Whale, 98.16%) wins on its note
and its sense of awe — not on the jolt. The bear, the rug, and the cabin are all 0x in
the top 100. This entry combines a primal jolt as strong as the Tiger's with a note as
good as the Whale's — plus a creature and a vessel nobody has tried.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` to the output directory. Node 22, standard library only.

## Concept notes

- **Jolt:** a rug that wakes up — the familiar object in the room turns out to be the
  monster. Amber eyes, roar, fangs, tongue, and a clawed paw breaking toward the viewer.
- **Note:** the child's note mirrors the Whale's winning format but with a darker punch
  line — grandpa was wrong — and a hand-drawn red heart.
- **Novelty:** grizzly bear, bearskin rug, and wooden cabin — none of them appear in the
  top 100, unlike the saturated whale (18x) and breakout (11x) motifs.
